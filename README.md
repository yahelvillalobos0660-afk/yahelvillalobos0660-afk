## 📌 Proyectos Destacados

### 📊 **Student Performance Analysis**
*Desarrollo de modelos predictivos y análisis estadístico en la educación superior.*
- **Descripción:** Proyecto de investigación y desarrollo donde utilicé algoritmos de Machine Learning (**SVM, Random Forest, Regresión Lineal**) para identificar los factores determinantes en el desempeño académico de estudiantes universitarios.
- **Aspectos clave:** Validación de datos mediante pruebas de hipótesis y herramientas estadísticas avanzadas para garantizar la rigurosidad de las observaciones.

### 💡 **Botón CUGDL (Proyecto de Innovación)**
*Solución tecnológica para la atención médica universitaria.*
- **Descripción:** Proyecto presentado durante el **Bootcamp de Innovación en CUGDL (2025)**, enfocado en optimizar el tiempo de respuesta y canalización de atención médica de emergencia dentro del plantel.

### 📚 **Mentoría y Preparación TOEFL iBT**
*Estrategia pedagógica adaptativa para certificación de idiomas.*
- **Descripción:** Diseñé un programa personalizado de asesoría de alto rendimiento enfocado en las 4 habilidades del idioma (Writing, Speaking, Listening, Reading), logrando que estudiantes alcanzaran certificaciones oficiales de nivel **B2**.
